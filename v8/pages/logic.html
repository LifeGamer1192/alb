How it works

Each combat turn the engine checks these rules top to bottom. The first rule whose condition is true decides the action. Drag a rule to change its priority.

Tip: a heal or support skill should be gated behind a condition (e.g. HP % < 40 → Use skill) so it does not fire wastefully.
