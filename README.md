# ALB — Auto Battle Lab (Public Demo)

This repository contains a small demo project for an auto-battler / idle roguelike.

- Demo site: https://lifegamer1192.github.io/alb/
- Public version: v3 (Character Build, Dungeon Generation and Simulation, Logic Editor placeholder)

Structure:

- `index.html` — Public demo homepage
- `pages/` — Demo pages: `build.html`, `game.html`, `logic.html`, `result.html`
- `css/` — Styles
- `js/` — Client-side scripts
- `data/` — JSON data files for cultures, classes, gods, skills, enemies

Goal: iterate features (build, dungeon generation, logic editor) and publish completed versions to the demo site.
