# ALB — Auto Battle Lab (Public Demo)

This repository contains a small demo project for an auto-battler / idle roguelike.

- Demo site: https://lifegamer1192.github.io/alb/
- Public version: v3 (character build with skill selection, dungeon generation and simulation)

Structure:

- `index.html` — Version selector landing page
- `v3/` — Latest public demo files and pages
- `v2/` — Archived previous version files and pages
- `css/` — Shared styles
- `js/` — Shared client-side scripts
- `data/` — Shared JSON data files for cultures, classes, gods, skills, enemies

Goal: iterate features (build, dungeon generation, logic editor) and publish completed versions to the demo site.
