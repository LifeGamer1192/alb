ALB Project — Public Demo (v11)

v11 adds a multi-skill loadout: equip up to three skills (each with its own cooldown) and let your logic rules decide which one to fire. New "Use skill 1/2/3" actions in the Logic Editor target a specific slot.

  • Character Build (3-skill loadout)
  • Logic Editor (per-slot skill actions)
  • Game (map + combat + effects)
  • Status (character + loadout)
  • Inventory (items)
  • Log (simple / detailed)
  • Result (latest run summary)
  • History (past runs & best records)
