How it works

Each combat turn the engine checks the active rule set top to bottom. The first rule whose conditions all match (AND) — or any match (OR) — decides the action.

Tip: combine conditions, e.g. HP % < 40 AND Enemy adjacent → Retreat. Keep separate rule sets for different builds.
