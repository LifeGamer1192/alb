ALB Project — Public Demo (v12)

v12 deepens the logic editor — compound AND/OR conditions, new conditions (floor, enemy HP, enemy type), new actions (retreat, attack weakest/strongest) and named rule sets you can switch between. Dungeon floors now randomly use one of three layouts: open rooms, a thin maze, or rogue-style cells.

  • Character Build (3-skill loadout)
  • Logic Editor (compound rules + rule sets)
  • Game (3 dungeon layouts)
  • Status (character + loadout)
  • Inventory (items)
  • Log (simple / detailed)
  • Result (latest run summary)
  • History (past runs & best records)
